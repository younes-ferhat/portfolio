## ⚙️ Getting Started

### ✅ Prerequisites

Make sure you have installed:

- **Node.js 18+**
- **pnpm**

---

### 📥 Installation

Clone the repository:

```bash
git clone https://github.com/younes-ferhat/portfolio.git
cd portfolio
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open in your browser:

http://localhost:3000
